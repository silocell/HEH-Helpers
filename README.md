# HEH-Helpers

The helper panel for Homework Launchpad, at **helpers.civilinitiatives.org**.

It is the same page as the admin panel (HEH-Maintenance-, maintenance.civilinitiatives.org),
kept identical: helpers see their smaller panel here, and the owner is sent on to
maintenance. The server decides what each account can do; this page only asks it.
